# 需求（对齐旧 h3c_tv_control 第一期）

作为家长，对每台电视（主卧/客厅/老人房/书房）能够：

1. 手动开/关电视网络（经本集成代理 → MQTT → Agent）
2. 设置单次最多上网 X 分钟（默认 30，范围 5–180）
3. 设置每天总共最多上网 Y 分钟（默认 90，范围 10–480）
4. 设置允许时段（全天 / 白天 / 夜间）
5. 超出任一条件时自动断网；单次用满后进入冷却（默认 60 分钟）
6. 每天 0 点自动重置当日统计；卡片支持「今日初始化」

## 与旧方案差异

| 项 | 旧 `h3c_tv_control` | 本集成 `h3c_tv_child` |
|----|---------------------|------------------------|
| 通断 | HA 内 Telnet | 绑定 MQTT Switch（h3c-tv-agent） |
| 状态校正 | 60s Telnet 轮询 | MQTT state / syslog 反馈 |
| 儿童策略 | 同左 | 同左（`child_policy.py`） |
| UI | `h3c-tv-child-card` | 同名卡片，域改为 `h3c_tv_child` |
